# 단원의 화첩 · 檀園 畵帖

조선 후기 화가 단원 김홍도(1745~1806년 이후)의 그림으로 푸는 **3D 미술 방탈출 게임**입니다. 고등학교 미술 감상 수업 한 차시(50분, 게임 35~40분)에 2~4명 모둠이 태블릿·노트북·스마트폰 브라우저로 함께 풀도록 만들었습니다.

> 미술반 체험학습으로 한옥 기념관 ‘단원 화첩관’을 찾았습니다. 그런데 전시실에 펼쳐 둔 「단원 풍속도첩」 복제본의 실이 풀리고, 화첩을 묶어 두던 낙관(도장) 일곱 개가 집 안팎으로 흩어졌습니다. 문 닫는 북이 울리고 대문이 잠깁니다. 마당과 방마다 그림을 들여다보며 도장을 되찾아, 마지막 별당에서 화첩을 다시 묶어야 밖으로 나갈 수 있습니다.

- 마당과 방 8곳, 낙관 7개, 실제 그림 18점, 곳마다 3단계 힌트
- 3D 장면(끌어서 둘러보기, ◆ 표시를 눌러 살펴보기)과 같은 내용의 2D 화면(설정에서 전환, WebGL이 없으면 자동)
- 한지 벽과 장판, 서까래, 창호 살, 기와와 초가, 종이빛 하늘의 수묵 산으로 꾸민 조선의 무대. 사람은 3D로 만들지 않고 그림 속 인물로 만납니다.
- 설치 없음, 회원가입 없음, 개인 정보 수집 없음

`index.html`을 브라우저로 열면 바로 시작합니다. GitHub Pages로 올리면 링크 하나로 반 전체가 쓸 수 있습니다.

## 수업에서 쓰는 법

| 단계 | 시간 | 하는 일 |
| --- | --- | --- |
| 도입 | 5분 | 「씨름」을 화면에 띄우고 “누가 이길까? 왜 그렇게 생각해?”만 묻습니다. 정답은 말하지 않습니다. 모둠 이름을 정합니다. |
| 게임 | 35분 | 모둠별로 진행합니다. 막히면 ‘힌트’를 씁니다(곳마다 3단계, 사용 횟수는 기록에 남음). 20분쯤 지나도 장터길에 못 간 모둠에는 서당 힌트를 권해 주세요. |
| 정리 | 10분 | 엔딩의 ‘우리 시대의 풍속화’ 질문으로 세 문장을 쓰고, 모둠 안에서 바꿔 읽으며 ‘들릴 것 같은 소리’ 한 문장을 덧붙입니다. 탈출 기록 화면을 캡처해 제출합니다. |

- 시작 화면의 **교사용 안내 · 정답**에 학습 목표, 수업 흐름, 곳마다 정답(접힌 상자 안), 사실과 이야기 구분, 접근성 안내가 있습니다.
- 진행 상황은 같은 기기·같은 브라우저에 자동 저장됩니다. 다음 반이 같은 기기를 쓰기 전에 설정(2D 화면은 오른쪽 아래)에서 **처음부터 다시**를 눌러 주세요.
- 느린 기기에서는 3D 화면의 **설정 → 간단한 2D 화면으로 보기**를 쓰세요. 퍼즐과 진행은 같습니다.

### 학습 목표

1. 김홍도의 풍속화와 산수·인물화를 조선 후기의 맥락 속에서 감상하고, 낙관(관서와 인장)을 읽어 작품의 정보를 찾을 수 있다.
2. 원형 구도와 시선, 표정, 여백, 시점(삼원법) 같은 조형 요소와 원리를 작품 해석의 근거로 들 수 있다.
3. 김홍도와 신윤복의 풍속화를 비교하고, 기록으로 확인되는 사실과 해석·추측을 구별할 수 있다.

2022 개정 교육과정 고등학교 「미술」의 감상 영역(작품을 맥락 속에서 이해하고, 근거를 들어 해석·비평하는 활동)과 연계됩니다. 성취기준은 학교 교육과정에 맞추어 골라 주세요.

## 사실과 이야기

- **‘단원 화첩관’은 지어낸 곳입니다.** 화첩이 풀린 사건, 지기의 쪽지, 흩어진 도장도 이야기를 위해 지어낸 것입니다. 실제 「단원 풍속도첩」(보물, 25면)은 국립중앙박물관에 있습니다. 사랑채 도장 상자의 복제 도장은 실제 김홍도의 도장 모양을 옮긴 것이 아닙니다.
- 김홍도의 생몰은 **1745~1806년 이후**로 적었습니다. 세상을 떠난 해는 기록이 분명하지 않습니다.
- 「단원 풍속도첩」의 그림 모두를 김홍도가 직접 그렸는지에 대해서는 **의문을 제기하는 연구도 있습니다.** 게임 안 ‘사실과 추측’ 안내판에 중립적으로 적었습니다.
- **‘※ 옛 기록 · 요약’** 표시가 붙은 글은 원문을 우리말로 줄여 옮긴 것입니다(요약 번역). 따옴표로 직접 인용하지 않았습니다: 강세황 「단원기」(호 ‘단원’이 명나라 화가 이유방의 호에서 왔다는 내용), 곽희 『임천고치』(삼원법), 『홍재전서』의 정조 관련 기록(그림 일을 김홍도에게 맡겼다는 뜻). 수업 전에 원문을 함께 확인하기를 권합니다.
- 그림에서 직접 확인한 글씨만 풀이했습니다: 「군선도」의 丙申春寫 · 士能, 「추성부도」의 乙丑 冬至後三日 丹邱寫, 「마상청앵도」의 檀園寫. 「마상청앵도」 위의 시는 지은이와 풀이가 자료마다 달라 다루지 않았습니다.
- 「씨름」에 손이 좌우로 바뀌어 그려진 구경꾼이 있다는 이야기는 이미지로 확인하기 어려워 넣지 않았습니다.
- 씨름의 승부, 서당의 앞뒤 이야기, 훈장의 표정, 여백의 까닭은 **그림을 근거로 한 해석**입니다. 게임은 흔히 가르치는 읽기를 정답으로 두되, 근거가 있는 다른 해석도 존중하도록 안내합니다.
- 도장 찍기, 삼원법 세 장면, 표정 판, 「마상청앵도」 복원판처럼 조작하는 그림은 게임용으로 새로 그리거나 원작을 잘라 쓴 것입니다.

## 접근성

- 색이 중요한 곳에는 색 이름을 함께 적었습니다(도장 돌 빛깔, 김홍도·신윤복의 색 비교). 도장은 새긴 한자로도 구별할 수 있습니다.
- 키보드로 모두 조작할 수 있습니다. 3D 화면은 화살표로 둘러보고, ‘살펴볼 것’ 목록으로 물건과 갈 곳을 고를 수 있습니다. 자물쇠 칸은 위아래 화살표로 돌립니다.
- 무동 마당의 악기 소리(Web Audio로 합성한 비슷한 소리)는 기본으로 꺼져 있고, 소리 없이도 설명과 그림만으로 풀 수 있습니다.
- 휴대폰 화면(가로 390px)에서도 가로 스크롤 없이 쓸 수 있습니다.
- 움직임 줄이기 설정을 켠 기기에서는 화면 움직임을 줄입니다.

## 기술 노트

- **파일 하나로 동작합니다.** `index.html` 하나에 게임 전체가 들어 있습니다. 크기는 약 3.8MB이며 대부분이 그림 데이터입니다.
- 외부에서 불러오는 것은 두 가지뿐입니다: three.js r128(`cdnjs.cloudflare.com`)과 Google Fonts(송명, 고운돋움, 나눔펜, Noto Serif KR, IBM Plex Mono). three.js를 불러오지 못하거나 WebGL이 없으면 자동으로 2D 화면으로 진행합니다.
- 3D 장면은 툰 셰이딩 재질과 먹선 윤곽, 캔버스로 그린 질감(한지, 장판, 우물마루, 창호 살, 기와, 초가, 먹 붓질 바위, 종이빛 하늘과 수묵 산)으로 만들었습니다. 낙관을 찾고 그림 조각을 붙이면 3D 장면에도 바로 반영됩니다.
- 진행 상황은 브라우저 `localStorage`의 `danwon-album-v1` 키에만 저장합니다. 서버로 보내는 데이터는 없습니다. 입력한 모둠 이름도 이 기기에만 남습니다.
- 로컬에서 열 때는 `index.html`을 더블클릭하면 됩니다(인터넷 연결 필요: three.js와 글꼴).
